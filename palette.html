Validation & Events

Enable Developer mode?

Developer mode exposes verbose diagnostics and development-only automation controls intended for testing Harness Builder.

Some development tools can capture the visible Fusion window or simulate input and may require macOS Screen Recording or Accessibility permission. Captures can include design names, geometry, paths, and other project information visible in Fusion.

Enabling Developer mode does not grant operating-system permissions or start capture or input automation. Each external QA run remains separately opt-in. Use these tools only on a development machine with suitable test data.
