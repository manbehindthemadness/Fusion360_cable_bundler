The geometry contracts remain distinct:

- An actual feature-capacity failure can carry its immutable measured reports
  into one coupled incident reflection using only unused work. Complete occupied
  internal fold/runway members retain independent finite-box separating planes.
  The new entry uses at most16dual working-set steps for up to13physical bounds,
  instead of discarding an uncleared constraint at a four-scalar representation
  limit. Original CPU/Newton/update/pair/hardware and physical gates stay strict.
- Cap certification uses the ordered physical mating frames; it cannot hide a
  material-side reversal in a normalized frame comparison.
- Fold derivatives and corrections stay inside the ordered fold domain. Only a
  measured domain boundary permits the existing incident-radius restoration,
  using genuinely remaining work and the physical radius floor.
- A fixed reversal that requires more angular travel than the remaining trust
  budget yields to the existing signed-joint continuation. That is a local
  strategy decision, not a claim of global geometric infeasibility.
- A terminal return requires strict material-crossing evidence to select its
  incident fold. Actual whole-profile contact and connector constraints join the
  cap equations; an ambiguous certificate is never a clearance pass.
- Sub-native straight slots are zeroed and the equations reclosed within the same
  work allowance. No output welding or target movement substitutes for closure.
- Identical equations and contact projections use bounded local caches, invalidated
  when the constraint set changes. Caches do not change traversal, arithmetic,
  comparison counts or acceptance limits and do not accumulate across test cases.
- Every immutable placed piece owns its computed endpoint frame. Reusing that
  exact frame avoids repeated material evaluations in closure and contact checks.
  A replaced piece owns a fresh frame; no global cache keeps old routes alive.
- Each immutable frame owns its normal. Direct component transforms retain the
  original zero-first arithmetic order while avoiding temporary vectors. Exact
  arithmetic/report replay is required; computation savings do not renew budgets.
