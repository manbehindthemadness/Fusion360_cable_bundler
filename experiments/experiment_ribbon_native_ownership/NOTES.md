# Original native ownership evidence

This experimental observer retains the original failed `MaterialFaces.seal_surfaces`
bookkeeping. It does not rebuild geometry, reconstruct a lost map, replay an audit,
or decide whether an uncovered face is acceptable. Use only on fresh owned gym
work with a frozen numerical/native source and the existing physical/resource gates.

Bind `Observer(MaterialFaces.seal_surfaces)` to the already loaded original function.
Use one new observer as a context manager around one synchronous host tester poll.
It temporarily installs `sys.setprofile`, matching only that function's code and
return event, including exception unwind. Existing profilers are refused; an
unexpected profile replacement is preserved and reported. No cached numerical,
native or geometry module is reloaded or patched. Do not install it across idle
poll intervals or into a numerical worker.

After the context exits, call `payload()` and write a new receipt. A failed seal
copies its original native face count, face/profile owners, per-region members and
query counts before the frame disappears. The body handle supplies its revision
only when collecting the payload outside the audit. Successful seals record a
count but no failed map. At most two failure maps are retained per poll; `overflow`
is a harness stop, never permission to continue or enlarge the record allowance.
A changed profile lease or missing receipt is also a harness stop. Keep the original
exception and native disposition, and report original partial dimensional warnings.

Observation adds Python callback/copying overhead inside the original native clock.
Do not use the instrumented run as a speedup comparison. Cold numerical workers and
their original CPU clocks are not profiled. The observer supplies no new native
queries, contact proof, cap certificate, repair, acceptance or independent case.

The original motivation was a fresh body that stopped at the lateral ownership seal
although read-only inspection found both real planar caps. Its lost ownership map
was recorded unavailable; it was never reconstructed or replayed. Future receipts
must distinguish missing source-region coverage, unowned native faces, cap ownership
and later seam/guide/cap fidelity. Do not infer a mapping defect from body validity
or terminal-center membership alone, and do not drop unowned faces to obtain a pass.
