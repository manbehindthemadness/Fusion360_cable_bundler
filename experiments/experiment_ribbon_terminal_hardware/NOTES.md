`Hardware.create(targets, start_dimensions, end_dimensions)` accepts explicit
width, height, depth and side/back clearance in millimeters. Scalable trial
defaults use joined profile width `W=(N+0.2)D`, proxy width `W+2D`, height `3D`,
depth `W` and clearance `D/4`. These are declared assumptions, not real hardware
dimensions or values fitted to successful routes. Clearance expands a rectangular
envelope on the sides and back, with its mating plane fixed; this is not a
Euclidean offset. Finite depth is essential: crossing the infinite terminal plane
elsewhere is not automatically a collision.

`check.inspect` encloses the full joined lobed profile and thickness against both
boxes using the existing analytic material interval projections. A strict interior
material point inside a box demonstrates intrusion. Clearance requires excluding
all material cells. Only the intended first/last cap receives the existing analytic
cap-side proof, with the actual terminal pose checked; later returning pieces get
no exemption. At most 512 cells and depth 36 are measured per route by default.
Exhaustion stays unresolved. This is floating interval evidence, not a formal proof,
actual connector fit certificate or native-body collision audit. Other solver rules
must still be checked separately. `view.draw` displays caller-owned boxes and the
same recorded witness without solving or changing the body.
